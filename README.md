# 💰 Expense Tracker

A professional and user-friendly **Expense Tracker Web Application** designed to help users manage daily income and expenses efficiently. The application allows users to record transactions, monitor their balance, categorize expenses, and keep track of their spending.

## 🚀 Features

* ➕ Add income and expense transactions
* ✏️ Edit existing transactions
* 🗑️ Delete transactions
* 📊 Calculate total income, expenses, and balance
* 🏷️ Categorize transactions
* 🔍 Search and filter transactions
* 📅 Track transactions by date
* 💾 Store data using browser Local Storage
* 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Local Storage**
